# VectraTech Solutions SpA

Sitio web institucional (una sola página, sin dependencias). Todo está en `index.html`.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub, por ejemplo `vectratech`.
2. Subir estos archivos (`index.html`, `.nojekyll`, `README.md`).
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)` → **Save**.
4. En uno o dos minutos queda en `https://<usuario>.github.io/vectratech/`.

## Dominio propio (opcional)

Si después se compra `vectratech.cl` en NIC Chile, se configura en **Settings → Pages → Custom domain**.
